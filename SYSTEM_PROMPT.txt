## 项目信息

- 配置: cmake -S . -B build -DCMAKE_CXX_COMPILER=g++
- 编译: cmake --build build -j
- 测试: ctest --test-dir build --output-on-failure
- 运行: ./build/testhub --port 8080 --language python --dir runners/python
- 语言: C++17，零第三方依赖，零警告
- 构建: CMake 3.16+，Linux / macOS / Windows
